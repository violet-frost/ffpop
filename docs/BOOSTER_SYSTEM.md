# 花果点点乐 · 四种辅助道具

实施日期：2026-11-23。沿用方案一50关；辅助道具与棋盘内生成的火箭、炸弹、彩虹分别管理。图标使用本次用户提供的原图，以SVG视口选取四个图案；源图为 assets/textures/garden_boosters.png，离线内嵌。

## 规则与交互

| 道具 | 操作 | 生效规则 | 边界 |
| --- | --- | --- | --- |
| 小木锤 hammer | 选道具，再点目标格 | 普通花果移除并计一个对应颜色；木箱移除并计箱；冰层只融冰并计冰 | 不命中相邻木箱，不生成或触发特殊棋子；融冰不收集里面花果；不能敲特殊棋子 |
| 园艺手套 glove | 选第一格，再选发光的上下左右相邻格 | 交换两个普通或特殊棋子，保留颜色、类型、身份 | 木箱、缺口和冰冻棋子不可交换；相同编码的无效交换不扣次数；交换后不自动消除、不掉落、不触发组合；若导致无普通合法操作则拒绝并恢复 |
| 调色花洒 watering | 选未冻结普通花果中心，预览后再次点击中心 | 将中心上下左右相邻的未冻结普通花果染为中心色；只改变不同颜色的格子 | 不作用于特殊棋子、木箱、缺口和冰层，不影响对角；不自动消除或生成道具；没有可变色邻格则不扣次数 |
| 幸运骰子 dice | 点击选中，再次点击骰子确认 | 重新排列全盘所有非缺口格中的完整对象，包括木箱、特殊棋子及附着冰层 | 固定缺口位置，保留各颜色、各类型、冰层总数与棋子身份；不收集目标、不重力塌落、不自动消除，不凭空补充特殊棋子 |

骰子使用确定性独立随机序列（关卡种子与累计道具次数），不消耗普通补充色号序列。最多尝试256次，选取布局确有变化且存在普通合法操作的一次；找不到时恢复棋盘且不扣次数。物件重新排列而非重新生成，所以骰子不会清掉障碍目标。重新排列后木箱的新位置会影响后续重力段。

四种道具均不扣普通步数，不增加普通回合数。每关分别限制各道具剩余次数与总体使用次数，两者同时满足才可使用。无效操作、预览和取消不扣次数。重开恢复本关配置，无跨关背包或货币。普通步数用尽并进入失败后不可再使用道具；星级沿用剩余步数标准。木锤可直接完成目标，随后进入正常胜利结算。

点击“取消”或Esc退出选择；选中同一非骰子工具可再次点击取消。手套或花洒可改选中心。游戏在动画期间锁定道具和棋盘；离开页面取消表现层。操作后读屏提示播报道具、剩余步数与剩余辅助次数。辅助操作改变布局后不继续高亮旧固定教学坐标。

## 配置与管线

唯一配置源仍为data/levels/level_001.json至level_050.json。boosters对象必须同时包含hammer、glove、watering、dice、maxUses：每种0—3，maxUses为0—8且不大于四种配额总和。boosterTutorial可选hammer/glove/watering/dice；省略boosters的旧配置默认全部不可用，不改变旧种子规则。

编辑器右侧“辅助道具”可修改配额、总上限与教学类型，支持撤销与草稿保存；试玩下方使用相同Game.useBooster规则，并把道具操作记入动作记录。试玩重开恢复，试玩不改配置。当前草稿键为bloom-editor-flow-v4，自动迁移上一版v3草稿并保留原键；掉落规则详见GRAVITY_RULES.md。

Excel“关卡配置”AA—AD为四种配额，AE为总上限，AF为教学类型；既有A—Z坐标保持。共有50行参数、450行布局。字段有整数范围验证，整体约束由共享Schema在导入前验证；拒绝非法配额时不改源文件。

```powershell
python build.py
node tools/validate_levels.cjs
python tools/export_workbook.py
python tools/level_io.py import "配置表路径.xlsx" --dry-run
```

实际导入时去掉--dry-run，导入器会备份原JSON并重建游戏和编辑器；随后重新生成策略报告与Excel，避免使用旧快照。可重跑author_levels.cjs生成新布局，但会覆盖当前50关，日常只用编辑器或Excel修改。

## 验证口径

50关仍逐一保留可回放的不使用辅助道具通关路线；前20关参考路线合计184步。报告按完整配置SHA256匹配。

不使用辅助道具的800路固定策略成功603路；独立的800路辅助策略成功652路，累计使用951次辅助工具。辅助策略完成教学前缀并消耗40%步数后，在配额内选用工具。两个数据均为程序策略样本，不代表真人通关率，也不证明任意使用工具都会提高胜率。Excel验证记录L—O保存辅助成功数、样本数、比例及累计使用数。

专项测试覆盖单格命中、融冰不收集颜色、交换不触发、十字染色边界、骰子数量与身份守恒、固定缺口、确定性、无效操作不改状态、总次数、重开和直接胜利。浏览器覆盖真实四种道具操作、预览确认、取消、动画锁、重开、6种竖屏尺寸、离开页面清理及编辑器配置试玩。Excel完成33列参数与JSON语义往返及原生Excel公式重算核验。
