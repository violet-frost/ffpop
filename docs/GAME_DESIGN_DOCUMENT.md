# 花果点点乐：游戏设计文档

## 定位与范围

花朵、水果主题的点击消除 HTML Demo，参考 Toon Blast 的核心同色连通消除体验，使用原创 SVG，不采用其素材。50 个关卡，5 章；包含花园主页、道路关卡地图、游戏页、成功/失败结果页及设置、帮助、目标确认、重开、章节解锁弹窗。任务、活动、商店、成就、好友只提供空白入口。保持当前实现效果，不新增外围系统。

## 页面与操作

首页：全屏手绘花园、小屋与白猫，左上真实通关进度、右上小设置图标；任务/活动在左，商店在右；下方绿色开始按钮显示第 N 关，底部主页/关卡/成就/好友导航。主按钮指向第一个未完成关卡；全部完成后指向第 50 关。

游戏：Android 竖屏单栏，上方木质 HUD 含白猫头像、目标卡、步数和实际目标完成进度；深色木框棋盘居中；底部圆形按钮为提示、玩法、重开、关卡、设置。棋盘 9 行 8 列，部分关卡有缺口。手机尺寸较小时按可视高度缩放，桌面居中显示同一竖屏画布。

结果：显示成功或失败、分数、已用/剩余步数和目标进度。成功后可下一关或重玩，第 50 关成功后可继续选关；失败可重试或换关。均可返回首页。

鼠标/触屏点击；键盘 Tab 进入棋盘、方向键移动焦点、Enter/空格消除，Esc 关闭弹窗。提示只标出当前推荐组合，不耗步、不自动执行。

## 消除与道具

只有横竖连通的同色普通棋子组成群组。至少两个才是有效点击；无效点击不扣步。每次有效点击扣一步。消除后按列补齐，不触发自动三消。

| 群组大小 | 生成 |
|---|---|
| 2–4 | 普通消除 |
| 5–6 | 火箭，随机横向或纵向 |
| 7–8 | 花瓣炸弹 |
| ≥9 | 彩虹花 |

生成道具保留于点击位置；若点击棋子带冰，不生成道具。火箭清一行或一列，炸弹清周围 3×3，彩虹花先点击选中发光，再点击上下左右相邻棋子交换，清除该棋子类型并清自身；点击非相邻位置取消，不耗步。冰冻棋子需先融化才能交换。火箭和炸弹可独立点击；被命中的道具连锁，连锁彩虹仍自动选择数量最多的颜色。

| 相邻道具组合 | 效果 |
|---|---|
| 双火箭 | 十字 |
| 火箭＋炸弹 | 三行三列 |
| 双炸弹 | 5×5 |
| 双彩虹 | 全盘 |
| 彩虹＋火箭/炸弹 | 以另一道具的颜色为多个效果中心 |

同一回合对同一格只处理一次命中。点击火箭或炸弹时，相邻多个特殊道具仍按原邻居顺序选择第一个伙伴；主动选择彩虹花时，以玩家指定的交换棋子为伙伴，其他道具在波及范围内连锁。

## 障碍与目标

木箱：在旁边消除或直接被道具命中时移除，每回合只计一次。冰层：首次命中融化，花果保留且不计该颜色收集；后续回合才能消除。缺口：不能填充；木箱与缺口分隔每列的重力区段，棋子不会跨越区段掉落。

全部收集目标达成即胜利，不以分数判胜；最后一步同时完成目标时优先判胜。步数归零且目标未齐则失败。无可用组合时免费重排。星级按剩余步数比例计算：≥35% 三星、≥15% 二星、其余一星。

普通移除每格 60 分，触发道具每个额外 150 分，相邻组合额外 300 分。分数仅作结果展示。

## 表现节奏与存储

动画与规则分离：规则即时生成结果，界面按交换（仅彩虹）→选中/蓄力→释放→消除→短暂停顿→真实分段掉落→回弹播放，结束后解锁。返回首页、重开、切关取消旧回合；胜负结果等待完整表现与额外 500ms 后出现。遵循系统「减少动态效果」偏好。

关键时长位于 `data/config/motion.json`（毫秒）：选中 70、蓄力 260、交换 240、火箭飞行 580、组合融合 220、彩虹连接 380、冲击火花 180、组合错峰 55、消除 220、停顿 85、掉落 460–760、每格额外 38、列间隔 14、回弹 90。复杂连锁可增加短暂错峰。

音效通过 Web Audio 合成；本地存储键 `bloom-pop-v1` 保存最佳星级和音效开关。没有账号、网络服务、体力、货币、养成、付费或社交。

棋盘取消普通棋子的方块底格，以花果轮廓、径向高光、底部厚度及投影表现体积。火箭从触发点向轴线两端发射，朝向与运动方向一致，规则仍为完整行/列。双火箭融合后交叉发射，火箭加炸弹三行三列齐射，双炸弹分层冲击波；彩虹组合先连接目标并显示道具转化，再依次引爆；双彩虹全盘连线与扩散。

## 2026-11-23 参考图风格统一

采用暖色木框、奶油面板、红色缎带标题、绿色立体按钮与手绘花园景观。关卡地图的节点沿中央道路分布，可滚动，旁边有樱花、溪流、瀑布、小屋与凉亭；顶部章节标题和 30 星进度来自真实星级。主页和地图的关卡入口必须先显示目标与步数，确认后才创建新 Game；取消确认不耗步、不覆盖当前游戏。

胜利/失败显示同一套缎带面板；胜利显示实际星级和分数。首次完成某章全部 10 关后，点击结算继续显示下一章解锁插画面板，再进入下一章地图；提示记录通过 announcedChapters 保存。Demo 仍允许自由选择全部 50 关。

任务、活动、商店、成就、好友只有标题和空白内容，不增加货币、体力、购买、奖励或社交逻辑。设置、帮助、重开、所有关闭按钮和空白面板都使用同一木框/缎带视觉。两张 JPEG 场景内嵌进单文件，无运行时联网或素材目录依赖。
