2026-11-23，Windows，本地 Chrome Headless，Node 及 Python 3。直接通过 file:// 打开交付 `index.html`，不启动游戏服务器，不使用外部网络资源。浏览器测试使用独立临时用户配置，不触碰日常 Chrome 数据。

## 浏览器验收

- 首页全屏场景、品牌、进度、设置与底部关卡按钮；标识不与主按钮重叠，页面无横纵溢出。
- 设置音效开关、帮助弹窗、跨章选到第 50 关、关闭弹窗及进入游戏。
- 正常消除时先保留旧棋盘，按阶段清除，再显示真正位移动画；落地后清理动画层和隐藏状态。
- 动画过程中快速重复点击只扣一次步数；切回首页中止旧回合；重新进入不残留锁定。
- 火箭蓄力与轨迹、炸弹扩散、彩虹连线出现在掉落之前。
- 提示不消耗步数；实际合法点击完成第一关并进入成功结果；下一关、重开可用。
- 第 50 关通过实际合法点击耗尽步数后进入失败结果，重试恢复配置。
- 减少动态效果路径可以正常完成回合。
- 竖屏视口：320×568、360×592、360×640、360×800、393×873、412×915；另含 390×844 与 320×740。检查棋盘完整位于屏幕、底部操作在屏内、无横向溢出。
- Android User Agent 与触屏模拟、浏览器工具栏占用高度、掉落中视口变化。
- 通过一关后回首页，主按钮指向第 2 关；刷新后保留星级与进度。
- 无页面 JavaScript 异常。

截图由浏览器测试生成于 `tests/screenshots/`，包含首页、棋盘、火箭/炸弹/彩虹表现、胜利和失败结果、六种手机尺寸。

## 验证结果

整理后版本：18 项核心检查通过，50 个固定种子在原配置下通过合法操作完成（同种子切换选择策略，合计 550 次尝试，最多 294 次；并非全部关卡由单一贪心策略一次完成）；50 个初始棋盘 / 1043 个未改规则回合与原版一致；28 条回放在已授权变更的主动彩虹操作前停止，新交换机制独立验证；4 项构建检查通过；完整浏览器验收通过，未出现 JavaScript 异常。

## 手动复核与限制

1. 双击根目录 `index.html`，无需安装依赖或联网，确认首页可见、可开始与选关。
2. 在真实 Android 手机浏览器检查地址栏收起/展开、安全区、旋转、触控大小及音效策略；当前自动化只有视口模拟，未声称已做真机验收。
3. 在 Safari / Firefox 中复核触控和音频；当前实际自动化浏览器为 Chrome。
4. 真人试玩检查曲线、道具可读性、掉落舒适度。自动通关不等同于玩家通关率。
5. file:// 本地存储策略依浏览器而异；新路径和原路径不承诺共享存档。存储被禁止时仍应能游玩。

## 修改后的复验策略

- 修改规则或关卡：先跑引擎与迁移对比。若玩法确有授权变更，记录预期差异，不直接覆盖基准掩盖问题。
- 修改模板、资源、样式或动画：先构建，再跑构建检查和浏览器验收。
- 所有源码改动后检查交付 `index.html` 与构建结果一致。
