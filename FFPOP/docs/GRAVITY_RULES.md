# 木箱障碍绕流与掉落规则

更新：2026-11-23。游戏、50关、关卡编辑器与Excel使用同一套flow规则。

## 修改前

旧版collapse把每列按木箱与缺口切成多个独立段；每段先向下压实，再从本段上方直接生成花果补满。因此木箱即使封死整行，下方仍会自产元素；元素只竖直移动，没有侧上方斜落。旧规则仍作为segment模式用于历史兼容测试。

## 新规则

1. 木箱固定占格，不能被花果穿过。先按列向下压实，普通花果和特殊棋子保持身份，现有冰层随所属棋子移动。
2. 只有棋盘静态区域顶部是补充入口：第1行，或缺口正下方的有效格。木箱不是入口，木箱下新形成的列段不能自产元素。缺口下方作为独立区域入口，保留既有关卡22的上下区域设计。
3. 完成直落与入口补充后，仍为空的有效格可接收左上或右上方棋子。依次从下往上、从左往右处理，同一目标优先左上来源，不额外抽取随机数。
4. 斜落必须来自可移动棋子，且来源下方的侧格不能是木箱或缺口，避免从两块障碍之间切角穿透。没有合法来源就保留空格。
5. 每轮斜落后重新进行直落和入口补充，直到稳定。既有花果只向更低行移动，不会上浮或纯横移。
6. 打破木箱后该格恢复通行，上方花果可以沿新通路下落。流动本身不消耗额外步数、不收集颜色目标、不触发特殊棋子或新组合；原本的消除规则保留。

示例：

```text
旧版：        新版可绕流：      新版完全封闭：
  木箱          A 木箱 B           箱 箱 箱
  空格          C 空格 D           C 空格 D
  ↓本段自产       ↘可从A/B流入       ↓保留空格
```

“优先直落”意味着斜落不会抢走一个本应直接向下填空的棋子。填入目标后会继续压实，下方未必停在第一格。木箱被骰子重新排列后，以其新位置计算下一次重力；骰子本身不触发重力，运行时空格也参与重排，固定缺口不变。

## 动画与空格

引擎记录每个移动棋子的逐段坐标和入口。表现层按记录播放竖直与斜向路径，不再把侧向流动裁在单列内。遮罩排除完整木箱和固定缺口，缺口下入口另加裁剪，避免新花果在上方区域提前露出。封闭形成的运行时空格仍是棋盘有效格，与永久缺口区分。

保留动画锁、离开页面中断、清理和减少动态效果设置。木锤敲除单格后的掉落也使用同一规则。

## 配置与编辑

- JSON字段gravity='flow'启用绕流；gravity='segment'或省略字段使用旧版，历史测试种子保持。
- 当前全部50关明确配置为flow。布局、目标、步数和种子均保留，只追加新掉落模式；按新规则重新生成参考解法。
- 编辑器“掉落规则”可切换模式，支持撤销并在试玩时调用同一引擎。
- 编辑器新草稿键为bloom-editor-flow-v4。若没有新版草稿，会读取原bloom-editor-boosters-v3，把未指定掉落模式的关卡迁移为flow，保留自定义编辑与旧草稿备份。
- Excel“关卡配置”AG列为gravity，取flow或segment，既有参数坐标保留；导入执行共享校验。

## 验证记录

8组重力规则测试通过：封闭不自产、直落优先、侧上斜落、禁止切角、破箱贯通、静态缺口入口、特殊与冰层身份守恒、确定性与稳定性。浏览器另验证真实路径遮罩、封闭空格、破箱补充、缺口下入口裁剪、动画中途取消和减少动态效果。

50关均有不使用辅助道具的可回放通关路线。前20关参考路线合计184步；固定800路基准策略成功603路，800路辅助策略成功652路，辅助工具累计使用951次。均为程序策略样本，不是人类通关率。

第49关在常规16路中成功0次，额外检索的第31路（0起编号30）找到参考解法。额外检索未计入16路比例；Excel验证记录P列单独保留参考策略编号，避免把“存在解法”混作“策略成功率高”。当前未据此压缩步数或修改目标。
