# 离线原创音频

- music_home.wav：向阳花园，76 BPM，50.53 秒循环。柔和中音区琴音、稀疏分解和弦与轻薄铺底，去掉低沉的超低音，主页/地图使用。
- music_game.wav：花间漫步，80 BPM，48 秒循环。与局外相同的温暖音色，稍有节奏变化；取消高八度装饰、密集音符与打击噪声。

两首由 tools/compose_music.py 使用 Python 标准库原创编曲与合成，可重复生成。PCM16 单声道 22050Hz，峰值分别为 0.36 / 0.34，尾音环绕以保持循环连续。构建器内嵌 WAV，离线可用。

道具使用中音区柔和提示音与少量滤波气流声，去掉爆炸重低音、尖锐上扫及密集铃音。音效总线额外保留 30% 增益，经 140 Hz 高通及 1600 Hz 低通柔化；音乐总线增益为 55%。同类音效 90ms 内合并，最多 16 个声部，减少连锁叠加冲击。各音效仍能区分。

音乐与音效独立调节，百分比使用平方增益曲线，0% 静音，保存于本地进度。首次用户操作后开始音乐；切到后台暂停，返回后恢复。

设置内无玩法说明入口。audioProfile=2 将旧存档总音量一次性设为 80%，保留其他滑块和关卡进度，此后尊重用户自定义音量。本轮音色调整不重置设置。
