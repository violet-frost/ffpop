# 花果点点乐 · 完整交付版本

本仓库包含游戏工程、关卡配置表、难度测试数据与报告、开发文档和图片素材。

- 游戏入口：[FFPOP/index.html](FFPOP/index.html)，下载仓库后可直接双击离线游玩。
- 关卡编辑器：[FFPOP/level-editor.html](FFPOP/level-editor.html)。
- 工程说明与验证命令：[FFPOP/README.md](FFPOP/README.md)，在 FFPOP 目录运行相关命令。
- 最新关卡配置表：[花果点点乐-关卡配置表.xlsx](花果点点乐-关卡配置表.xlsx)。
- 数据、报告、Excel 和预览图：outputs/。
- 原始图片：花果消消乐-图片/。
- 开发者文档、初步总结和最终总结：仓库根目录的 Word 文档。

保留 FFPOP 与 outputs 的同级目录结构；部分工具及测试使用此相对路径读取交付数据。Node 依赖、Python 缓存及 Office 临时锁文件不纳入版本管理。
